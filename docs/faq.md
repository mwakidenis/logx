# Frequently Asked Questions

## What is LOGX?

LOGX is a modular, zero-dependency JavaScript and TypeScript utility library.

## Does LOGX have runtime dependencies?

No. Zero runtime dependencies.

## What Node.js versions are supported?

Node.js >= 20.

## Can I use LOGX in the browser?

Yes. LOGX works in modern browsers. Browser-specific features degrade gracefully.

## Does LOGX support tree-shaking?

Yes. `"sideEffects": false` and independent module entrypoints enable tree-shaking.

## Is LOGX TypeScript-ready?

Yes. TypeScript declarations ship with the package.

## Can I mutate input arrays/objects?

No, unless explicitly documented. LOGX does not mutate user data.

## How do I report a security issue?

Contact the maintainer through GitHub. Do not open public issues.

## Who maintains LOGX?
