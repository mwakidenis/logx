# Governance

## Maintainer responsibilities

The maintainer is responsible for:
- Reviewing and merging pull requests
- Managing releases and versioning (semantic versioning)
- Maintaining documentation and API stability
- Responding to security reports
- Enforcing the code of conduct

## Contributor recognition

Contributors are acknowledged in the CHANGELOG. No additional governance members are appointed at this time.

## Changes

Changes to governance are proposed through pull requests and decided by the maintainer.
