# Security Policy

## Supported versions

LOGX is in initial development (0.1.0). Security fixes are applied to the latest release.

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities. Email the maintainer, Mwaki Denis, through GitHub with details of the vulnerability.

## Scope

- Safe string comparison
- HTML escaping
- Cryptographically secure random generation using platform APIs

LOGX does not implement cryptographic algorithms. Encoding, hashing, and HTML escaping are not presented as complete security solutions.

## Disclosure

Reports will be acknowledged within 5 business days. Fixes are released through the standard Changeset release process.
